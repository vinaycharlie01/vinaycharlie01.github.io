Writing a Kubernetes Operator in Go for Instana ​

Managing the Instana lifecycle across clusters gets repetitive. A Kubernetes Operator in Go turns "desired Instana state" into a custom resource that the control loop keeps reconciled.

The reconcile loop ​

The core of an operator is a loop that compares the desired state with the live state and takes the smallest step to close the gap:

go
func (r *InstanaReconciler) Reconcile(ctx context.Context, req ctrl.Request) (ctrl.Result, error) {
    instana := &instanav1.Instana{}
    if err := r.Get(ctx, req.NamespacedName, instana); err != nil {
        return ctrl.Result{}, client.IgnoreNotFound(err)
    }

    // ensure Helm release, config, and status are in sync...
    return ctrl.Result{}, nil
}

What the operator owns ​

  • Installing and upgrading the Instana agents from a Helm chart.
  • Controlling chart values with flags and defaults.
  • Writing status back to the custom resource so the user can see drift.

Why Go ​

Go's client-go library is the same API the Kubernetes controllers use, so the operator stays close to the platform. Static typing and good concurrency support make the reconcile loop easy to reason about.
